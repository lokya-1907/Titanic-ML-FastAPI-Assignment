# Titanic ML Inference Strategies and FastAPI

This project implements the assignment using the Titanic `train.csv` dataset from Kaggle.

## Project contents

- `train_model.py` — splits labelled data into training/testing portions, trains one sklearn pipeline, evaluates accuracy, and saves `model.pkl` plus held-out test records.
- `online_inference.py` — predicts one held-out passenger.
- `batch_inference.py` — predicts 20 held-out passengers and writes `batch_predictions.csv`.
- `streaming_inference.py` — simulates 10 records arriving one at a time with a one-second delay.
- `app.py` — FastAPI `/health` and `/predict` endpoints with Pydantic validation.
- `client.py` — sends a prediction request to the API.
- `observations_report.pdf` — brief report containing the four required observation answers.
- `requirements.txt` — dependencies.
- `screenshots/` — put your own screenshots of the real outputs here.

## Dataset

Download `train.csv` from the official Kaggle Titanic competition data page:
https://www.kaggle.com/competitions/titanic/data

`train.csv` is included in this ZIP from the dataset you uploaded. The model and prediction CSV are generated by running the included scripts against this actual dataset.

## Setup (Windows PowerShell)

```powershell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
pip install -r requirements.txt
```

If PowerShell blocks activation, use:
```powershell
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
.\.venv\Scripts\Activate.ps1
```

## Run the assignment

Run commands from this folder, in order:

```powershell
python train_model.py
python online_inference.py
python batch_inference.py
python streaming_inference.py
```

The training script creates:
- `model.pkl` — the complete fitted preprocessing + model pipeline.
- `test_records.csv` — 20+ held-out passenger records with no target column.
- `test_labels.csv` — labels for evaluation/reference only; inference scripts do not use these labels.
- `training_metrics.json` — test accuracy and split details.

Start FastAPI in one terminal:
```powershell
uvicorn app:app --reload
```

Open `http://127.0.0.1:8000/docs` in a browser. Test `GET /health`, then `POST /predict` with a valid passenger body. To test validation, use an invalid value such as `"Pclass": 4`; Pydantic should return HTTP 422.

In a second terminal:
```powershell
python client.py
```
